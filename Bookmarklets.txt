WorkBookmarklets - loader URLs
==============================

Each entry below is a full "javascript:" bookmarklet. Drag/paste it into
a bookmark's URL field. Clicking it fetches the real script fresh from
GitHub every time (cache-busted via ?_=<timestamp>), so edits pushed to
this repo take effect immediately - no need to re-save the bookmarklet
itself.

Same loader pattern for every entry (matches Konnect-Notes-Bookmarklet.txt):
fetch -> check response.ok -> Function(code)() -> alert on failure.

--------------------------------------------------------------------

Work Tools (one bookmark for all the tools)

Opens the right tools for the page: Lead Checker on Konnect Live, SLA
Manager on Konnect Manager, and Konnect Notes, Reg Check (Alt+R) and Lead
Re setup on the agent desktop. Reg Check is only loaded by Work Tools on
the agent desktop; anywhere else use its own bookmark below. Clicking Work
Tools again on the agent desktop is safe during a run: it loads whatever
is missing and shows the Lead Re setup panel that is already there. The
Konnect Tools bookmark other staff use is separate and unchanged.

javascript:(async function(){try{const url="https://raw.githubusercontent.com/OmariDC/WorkBookmarklets/main/Work-Tools.js?_="+Date.now();const response=await fetch(url);if(!response.ok)throw new Error("HTTP "+response.status);const code=await response.text();Function(code)();}catch(e){alert("Error loading Work Tools: "+e);}})();

Lead Re setup (agent desktop)

One panel with three runs:
- Re setup: adds each of the National check's Re setup leads back as a new
  lead and parks the call. On a customer already open it sets a chosen
  closed lead up again and stops in the new lead. Never presses Finished.
- Post Closure: opens each "send back through" lead from Parked Calls,
  types cad or cah in Post Closure Notes (Konnect Notes writes the note),
  sets Customer Hub Team > No Opportunity > Catch All and presses Finished.
  Parked Calls are checked on the Lead Checker through SLA Manager.
- Email Only: works the Email Only leads assigned in SLA Manager as they
  present: Reject, Update Outcomes, eo in Call Notes, Customer Hub Team >
  Ongoing > Email Only Lead, then Finished.

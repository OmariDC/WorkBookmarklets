WorkBookmarklets - loader URLs
==============================

Each entry below is a full "javascript:" bookmarklet. Drag/paste it into
a bookmark's URL field. Clicking it fetches the real script fresh from
GitHub every time (cache-busted via ?_=<timestamp>), so edits pushed to
this repo take effect immediately - no need to re-save the bookmarklet
itself.

Same loader pattern for every entry (matches Konnect-Notes-Bookmarklet.txt):
fetch -> check response.ok -> Function(code)() -> alert on failure.

--------------------------------------------------------------------

Auto-AcceptLP

javascript:(async function(){try{const url="https://raw.githubusercontent.com/OmariDC/WorkBookmarklets/main/Auto-AcceptLP.js?_="+Date.now();const response=await fetch(url);if(!response.ok)throw new Error("HTTP "+response.status);const code=await response.text();Function(code)();}catch(e){alert("Error loading Auto-AcceptLP: "+e);}})();
